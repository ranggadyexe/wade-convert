# ADR 0001: Memakai lisensi AGPL-3.0

- Status: Diterima
- Tanggal: 2026-09-28

## Konteks
Proyek berupa layanan web dan open source. PyMuPDF dan Ghostscript berlisensi AGPL; penggunaannya di layanan online mewajibkan kode sumber dibuka.

## Keputusan
Proyek dilisensikan AGPL-3.0.

## Konsekuensi
- Bebas memakai PyMuPDF/PyMuPDF4LLM dan Ghostscript.
- Modifikasi yang dijalankan sebagai layanan publik wajib dibuka.
- Sulit dijadikan produk closed-source di masa depan tanpa lisensi komersial.
